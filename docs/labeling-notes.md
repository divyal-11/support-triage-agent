# Evaluation Set — Sampling & Labeling Notes

> **Files:** `data/golden-set.json`, `data/golden-set.original-labels.json`, `data/golden-set.v2.json`  
> **Total Samples:** 200 examples  
> **Status:** Machine-labelled evaluation set (not human-verified).

---

## 0. Label Provenance

Neither evaluation set was reviewed or verified by a human annotator:
- **Original labels (`data/golden-set.json`, backed up in `data/golden-set.original-labels.json`):** Generated by an automated heuristic script using keyword rules, regular expressions, and heuristics based on historical `@SpotifyCares` replies. No manual human review took place.
- **V2 labels (`data/golden-set.v2.json`):** Produced by an LLM / automated classification script using prompt taxonomy guidelines, also with no human review or manual validation.

Because both sets of labels were generated by automated scripts rather than human annotators, metrics evaluated against these sets measure agreement with machine-generated labels, not real-world ground truth accuracy.

---

## 1. Sampling Methodology & Reproducibility

1. **Source Corpus:** Sampled from the 13,922 `@SpotifyCares` customer-reply pairs (`data/spotifycares-pairs.json`).
2. **Quality Pre-Filter:** Excluded low-signal tweets (standalone URLs, single emojis, or queries with fewer than 3 words) to remove empty entries.
3. **Deterministic Sampling:** Shuffled using a seeded Mulberry32 pseudo-random number generator (`seed = 42`) in `src/build-labeling-sheet.ts`.

## 3. Labeling Heuristics Used by the Generating Script

When the heuristic script assigned labels to ambiguous or multi-intent messages, it applied the following precedence order:

1. **Security (`account_access_security`):** Keywords for hacked playlists, password resets, or CSRF tokens. Flagged `should_escalate: true`.
2. **Billing (`billing_payment_dispute`):** Keywords for unauthorized charges, double billing, or student discounts. Flagged `should_escalate: true`.
3. **Family Plan (`subscription_plan_family`):** Mentions of family plan invites or sub-accounts. Flagged `should_escalate: true`.
4. **Technical Support:** Keywords for playback, downloads, crashes, or catalog requests. Flagged `should_escalate: false`.

---

## 4. Test Set Isolation

- **Held-Out Set:** These 200 samples were excluded from the silver training set (`data/silver-set.json`) used to fit the TF-IDF classifier.
- **Limitation:** While held out from model training, the labels remain machine-generated and subject to heuristic rule biases.
